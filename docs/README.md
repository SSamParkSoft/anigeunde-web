# 아니근데 개발 문서

에이전트와 개발자는 루트 [`AGENTS.md`](../AGENTS.md)를 먼저 읽고 아래 문서를 사용한다.

## 문서 지도

| 문서 | 역할 |
|---|---|
| [`plans/active/README.md`](./plans/active/README.md) | 현재 진행 중인 구현 문서 색인 |
| [`../anigeunde-service-design.md`](../anigeunde-service-design.md) | 제품, 데이터, 운영, 보안과 법적 위험을 포함한 전체 설계 |
| [`../infra/README.md`](../infra/README.md) | OCI Ubuntu 서버 초기 설정 |
| [`../README.md`](../README.md) | 로컬 실행, 검증 명령과 현재 구현 상태 |
| [`brand-identity.md`](./brand-identity.md) | 확정 로고 방향, 자산 위치와 사용 규칙 |

## 상태 규칙

- `plans/active/`: 아직 구현 또는 검증이 끝나지 않은 작업
- `plans/completed/`: 완료 기준을 충족하고 검증 결과가 기록된 작업
- 문서의 `상태`, `최종 갱신일`, `완료 기준`을 반드시 유지한다.
- active 문서는 희망사항이 아니라 다음 구현자가 따를 수 있는 구체적인 계약이어야 한다.
