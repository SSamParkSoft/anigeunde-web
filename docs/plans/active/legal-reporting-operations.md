# 커뮤니티 신고와 권리침해 처리 운영

- 상태: `ACTIVE`
- 최종 갱신일: `2026-08-18`
- 대상: 정책 페이지, 신고 UI, 관리자 도구, 개인정보 및 법적 요청 운영
- 공개 문서: [`커뮤니티 운영정책`](../../../apps/web/app/community-guidelines/page.tsx), [`권리침해 신고 안내`](../../../apps/web/app/rights/page.tsx)

## 1. 목적

일반 이용자의 커뮤니티 규칙 위반 신고와 권리자·피해자의 법적 권리침해 요청을 접수 단계부터 분리한다. 공개 문구뿐 아니라 접수 분류, 처리기한, 당사자 통지, 증거 접근과 보유기간이 실제 운영에서 동일하게 동작해야 한다.

## 2. 확정된 분류

| 유형 | 신청인 | 주요 처리 기준 | 기본 제목 |
|---|---|---|---|
| 일반 신고 | 누구나 | 커뮤니티 운영정책 | `[아니근데 일반신고]` |
| 명예·사생활·개인정보 권리침해 | 피해자·정보주체·대리인 | 정보통신망법 제44조의2 등 | `[아니근데 권리침해 요청]` |
| 저작권 중단 | 권리주장자·대리인 | 저작권법 제103조 및 시행령 | `[아니근데 저작권 중단 요청]` |
| 저작권 재개 | 복제·전송자 | 저작권법 제103조 및 시행령 | `[아니근데 저작권 재개 요청]` |
| 긴급 위해·불법촬영물 등 | 누구나 | 관계 법령과 긴급 대응 기준 | `[긴급]` 우선 분류 |

일반 신고에는 권리자 신원이나 대리권 자료를 요구하지 않는다. 법적 권리침해 요청에는 대상, 권리관계, 침해 사실과 회신 수단을 확인한다.

## 3. 현재 공개 문서의 계약

- 일반 신고와 운영조치 이의제기는 커뮤니티 운영정책에서만 상세히 설명한다.
- 권리침해 안내는 삭제·반박내용 게재·임시조치와 저작권 중단·재개 절차를 설명한다.
- 정보통신망법 제44조의2에 따른 조치를 하면 신청인과 정보게재자에게 즉시 통지한다.
- 권리침해 신고·조치 기록의 보유기간은 처리 완료 후 1년이며, 진행 중인 분쟁·수사·소송은 종료 시까지 연장할 수 있다.
- 일반 운영조치 이의제기 30일은 저작권 재개 요청 등 법정 절차를 대체하지 않는다.

## 4. 관리자 처리 상태

```text
RECEIVED
  → NEEDS_INFORMATION
  → TRIAGED
  → TEMPORARILY_HIDDEN
  → ACTIONED 또는 REJECTED
  → APPEALED
  → RESTORED 또는 CLOSED
```

모든 전환에는 요청 유형, 담당자, 이전·이후 상태, 시각, 사유, 통지 여부와 근거자료 식별자를 남긴다. 신고 원문과 첨부파일은 일반 애플리케이션 로그에 기록하지 않는다.

## 5. 제품 요구사항

### 5.1 이용자 화면

- 모든 의견·댓글에 신고 버튼을 제공한다.
- `운영정책 위반`, `내 권리 침해`, `저작권`, `불법촬영물·아동 성착취물`, `생명·신체 긴급 위험`을 첫 단계에서 구분한다.
- 일반 신고에는 URL과 사유만 요구한다.
- 권리침해와 저작권을 선택하면 전용 안내와 필요한 소명자료를 표시한다.
- 고위험 콘텐츠는 다운로드·재전송하지 말라는 안내와 112·119 등 외부 긴급기관 정보를 먼저 표시한다.

### 5.2 관리자 화면

- 신고 유형별 대기열과 긴급 우선순위를 제공한다.
- 숨김, 삭제, 복원, 댓글 잠금, 계정 제한과 집계 제외를 별도 동작으로 기록한다.
- 신청인·게시자 통지문을 생성하고 발송 성공·실패를 기록한다.
- 원문 접근은 최소 역할로 제한하고 열람 감사 로그를 남긴다.
- 법정 처리와 일반 운영조치를 하나의 버튼으로 뭉치지 않는다.

## 6. 저작권 절차

- 중단 요청은 문화체육관광부령상 요청서와 권리 소명자료를 받는다.
- 요건을 갖춘 중단 조치 후 시행령상 3일 이내 통보 절차를 수행한다.
- 복제·전송자는 중단 통보일부터 30일 이내 재개 요청할 수 있다.
- 재개 요청일부터 3일 이내 정당한 권리 여부를 판단한다.
- 재개를 결정하면 요청일부터 7일 이후 14일 이내로 재개 예정일을 정하고 권리주장자에게 통지한다.

## 7. 출시 전 미충족 사항

- [ ] 저작권법상 수령인의 성명과 소속부서 확정
- [ ] 수령인의 업무용 전화번호와 팩스번호 준비
- [ ] 수령인의 이메일과 우편주소를 포함한 정식 공지
- [ ] 법정 중단·재개 요청서 다운로드 또는 전자 제출 기능
- [ ] 게시자와 신청인의 통지 수단 등록
- [ ] 신고·첨부파일 저장소 암호화와 접근 통제
- [ ] 처리 완료 후 1년 보유 및 자동 파기 작업
- [ ] 긴급 신고 당직·연락 체계와 운영 가능 시간 공개
- [ ] 신고 처리 담당자 교육과 모의훈련

현재 공개 페이지의 이메일은 일반·사전 접수 창구다. 위 정보가 갖춰지기 전에는 이를 저작권법상 정식 수령인 지정 공지라고 표현하지 않는다.

## 8. 완료 기준

- [ ] 일반 신고와 권리침해 요청이 서로 다른 입력·대기열로 접수된다.
- [ ] 권리자 자료를 일반 신고자에게 요구하지 않는다.
- [ ] 임시조치 기간과 당사자 통지가 자동 추적된다.
- [ ] 저작권 중단·재개 서식과 법정 기한이 자동 추적된다.
- [ ] 공개 정책, 개인정보처리방침과 실제 보유기간이 일치한다.
- [ ] 운영자 원문 열람과 모든 상태 변경이 감사 로그에 남는다.
- [ ] 수령인 정보가 법정 공개 요건을 충족한다.
- [ ] 법률 전문가의 출시 전 최종 검토 결과가 반영된다.
