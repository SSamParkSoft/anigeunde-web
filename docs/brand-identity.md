# 아니근데 브랜드 아이덴티티

- 상태: 적용됨
- 최종 갱신일: 2026-08-18

## 확정 방향

- 기본 워드마크는 굵고 둥근 `아니근데.` 한글 조판을 사용한다.
- 심볼은 `아`의 원형, 대화의 말꼬리, 짧은 반론을 나타내는 밑줄, 마침표를 결합한다.
- 기본 색상은 `#080808`과 `#f7f7f3`만 사용하며, 검은 배경에서는 반전한다.
- 파비콘에서는 글자 전체를 축소하지 않고 심볼만 사용한다.

## 사용 자산

| 파일 | 용도 |
|---|---|
| `apps/web/public/brand/anigeunde-mark.svg` | 원본 심볼 |
| `apps/web/public/brand/anigeunde-wordmark.svg` | 심볼과 한글 워드마크 조합 |
| `apps/web/public/brand/anigeunde-mark-512.png` | 외부 서비스용 512px 심볼 |
| `apps/web/app/icon.svg` | SVG 브라우저 아이콘 |
| `apps/web/app/favicon.ico` | 16, 32, 48px 브라우저 파비콘 |
| `apps/web/app/apple-icon.png` | 180px Apple 홈 화면 아이콘 |

## 사용 규칙

- 심볼 내부의 비율, 원형 구멍, 말꼬리와 마침표 위치를 임의로 변경하지 않는다.
- 심볼 주변에는 최소한 마침표 지름만큼의 여백을 둔다.
- 워드마크의 글자를 이미지 생성 결과로 대체하지 않는다. 실제 서비스에서는 정확한 한글 텍스트와 번들된 Wanted Sans를 사용한다.
- 그라데이션, 그림자, 외곽선 또는 별도 강조색을 추가하지 않는다.
